# RTL Chat — مواصفة التصميم

إضافة فايرفوكس تصلّح اتجاه النص العربي في مواقع الشات بالذكاء الاصطناعي، وتُنشر
رسمياً على addons.mozilla.org (AMO) كإضافة عامة (listed).

## الهدف

المستخدم يكتب ويقرأ بالعربي في ChatGPT و Claude و Gemini وغيرها، والمواقع تعرض
الفقرات العربية بمحاذاة اليسار، وتضع نقاط القوائم والترقيم في الجهة الخطأ، وتبدأ
خانة الكتابة من اليسار. الإضافة تصلّح هذا في كل المواقع المدعومة من مكان واحد.

معيار النجاح: رد عربي فيه فقرات وقائمة مرقمة وجدول وكود يظهر كله بالاتجاه الصحيح،
والرد الإنجليزي في نفس المحادثة لا يتغير، وواجهة الموقع لا تنكسر.

## السلوك

### الوضع التلقائي (الافتراضي)

كل عنصر نصي داخل الرسائل وخانة الكتابة يأخذ اتجاهه من أول حرف قوي فيه:

- الفقرات والعناوين والاقتباسات: `unicode-bidi: plaintext` و `text-align: start`
  عبر CSS.
- القوائم (`ul`, `ol`) والجداول والاقتباسات: السكربت يضع `dir="auto"` عليها، لأن CSS
  وحده لا ينقل النقاط والترقيم وترتيب الأعمدة.
- خانة الكتابة (`textarea` أو `contenteditable`): `dir="auto"`.
- الأكواد (`pre`, `code`) والمعادلات (KaTeX/MathJax): `direction: ltr` دائماً.
- واجهة الموقع (القوائم الجانبية، قوائم الأوامر، أشرطة الأدوات): لا تُلمس.

### وضع RTL الإجباري

اختياري من النافذة المنبثقة: كل عناصر النص وخانات الكتابة RTL بغض النظر عن
المحتوى. الأكواد والمعادلات تبقى LTR. الاختيار يسري على كل المواقع.

### الإيقاف

لكل موقع مفتاح تشغيل/إيقاف. الإيقاف يزيل كل ما أضافته الإضافة (الـ CSS والخصائص)
بدون إعادة تحميل الصفحة.

## البنية

Manifest V3، بدون مكتبات وبدون خطوة build.

```
manifest.json
src/
  sites.js        تعريف المواقع: النطاق + selectors إضافية خاصة بكل موقع
  direction.js    منطق الاتجاه الصرف: الإعدادات، نص الـ CSS، أي عناصر تأخذ dir
  content.js      يقرأ الإعدادات، يطلب الـ CSS، يشغّل MutationObserver
  background.js   يحقن الـ CSS، ويسجّل content script للمواقع التي أضافها المستخدم
  popup/          popup.html, popup.js, popup.css
_locales/ar, _locales/en
icons/
tests/
  unit.test.js    المنطق الصرف
  browser/        صفحة محاكاة + فحوص تعمل داخل فايرفوكس headless
```

- القواعد العامة تطبّق على كل موقع، مدعوم أو مضاف: `p, li, h1–h6, blockquote, td,
  th` وما شابهها، وخانات الكتابة. `sites.js` يضيف فوقها فقط ما يخص موقعاً بعينه
  (حاوية نص غير قياسية، خانة كتابة، جزء من الواجهة يُستثنى)، وهو المكان الوحيد الذي
  يعرف selectors المواقع.
- واجهة الموقع تُستثنى بقاعدة عامة: كل ما هو داخل `nav` أو `aside` أو عنصر بدور
  قائمة أو شريط أدوات لا يُلمس.
- الـ CSS يُبنى نصاً في `direction.js` ويحقنه `background.js` عبر
  `scripting.insertCSS`، فلا تمنعه سياسة CSP للموقع.
- القوائم التي تصير RTL تأخذ إزاحة من جهة البداية، لأن كثيراً من المواقع تزيح
  القوائم بـ `padding-left` فتخرج النقاط عن الصندوق.

### تدفق البيانات

الإعدادات في `browser.storage.sync`: `{ mode: "auto" | "rtl", disabled: [hostnames] }`.
النافذة المنبثقة تكتب، و `content.js` يستمع لـ `storage.onChanged` ويطبّق فوراً.
أي قيمة ناقصة أو غير صالحة ترجع للوضع التلقائي المفعّل.

المواقع المضافة ليست في الإعدادات: هي أذونات النطاقات التي منحها المستخدم.
`background.js` يقرأها من `permissions.getAll` عند كل منح أو سحب ويحدّث content script
واحداً مسجّلاً عليها.

### الأداء

MutationObserver واحد على الصفحة، يعالج العقد المضافة فقط، ومجمّع عبر
`requestAnimationFrame` حتى لا يتعثر أثناء بث الرد. الوضع الإجباري CSS فقط بدون
مراقب.

## متطلبات النشر على AMO

- `browser_specific_settings.gecko.id` ثابت: `rtl-chat@musaad-sharikh`.
- `browser_specific_settings.gecko.data_collection_permissions` مع
  `required: ["none"]` — الإضافة لا تجمع ولا ترسل أي بيانات.
- `strict_min_version` هو `142.0`، أول إصدار يقبله `web-ext lint` مع مفتاح
  `data_collection_permissions` بدون تحذير.
- أقل أذونات ممكنة: `storage`, `scripting`, `activeTab`، و `host_permissions`
  للنطاقات العشرة فقط، و `optional_host_permissions` للباقي. لا `tabs`.
- لا كود خارجي ولا طلبات شبكة.
- أيقونات 48 و 96، وصف عربي وإنجليزي في `docs/amo-listing.md`.
- سطح المكتب فقط. لا يوجد مفتاح `gecko_android`.
- الاسم العام **RTL Chat**، والترخيص **MIT**.

## الاختبار

- `npm run test:unit`: المنطق الصرف بـ `node --test`، وتطابق الترجمتين، وتطابق
  نطاقات `manifest.json` مع `sites.js`.
- `npm run test:browser`: يشغّل `content.js` الحقيقي داخل فايرفوكس headless على صفحة
  محاكاة، ويقيس الاتجاه الفعلي بعد التخطيط: فقرات عربية وإنجليزية ومختلطة، قوائم،
  جدول، كود، خانة الكتابة، البث عقدة عقدة، الوضع الإجباري، الإيقاف، والاسترجاع.
- `npm run lint`: `web-ext lint` عبر `npx`.
- يدوي: تحميل مؤقت من `about:debugging` وتجربة كل موقع بعد تسجيل الدخول. الـ selectors
  الخاصة بكل موقع في `sites.js` لا تتأكد إلا بهذه الخطوة.

تغيير الخطوط، ترجمة واجهات المواقع، Chrome، أندرويد، مزامنة إعدادات خارج
`storage.sync`.
